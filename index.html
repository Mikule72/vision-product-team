⚠️ Configuration Firebase requise — À faire une seule fois
  1. Créez un projet sur console.firebase.google.com
  2. Activez Firestore Database (Build > Firestore > Créer en mode test)
  3. Paramètres du projet > Vos apps > </> > copiez l'objet firebaseConfig
  4. Éditez ce fichier HTML, collez la config dans la section [1] FIREBASE CONFIG
  5. Ouvrez dans un navigateur, DevTools console (F12) > cliquez le lien Firebase pour créer l'index
