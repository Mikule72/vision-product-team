Configuration Firebase requise — À faire une seule fois
  1. Créez un projet sur console.firebase.google.com
  2. Activez Firestore Database (Build > Firestore > Créer une base de données > Mode test)
  3. Dans Paramètres du projet > Général, créez une app Web (</>) et copiez l'objet firebaseConfig
  4. Ouvrez ce fichier HTML dans un éditeur et collez la config dans la section [1] FIREBASE CONFIG
  5. Rechargez la page, ouvrez la console DevTools (F12) > cliquez le lien Firebase pour créer l'index automatiquement
  6. Hébergez le fichier (GitHub Pages, Netlify, Google Drive…) et partagez le lien avec l'équipe
